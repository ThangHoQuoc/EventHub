# EventHub Modern UI/UX Design DNA

## 1. Visual Aesthetics & Philosophy
- **Style**: Modern Event Ticketing Platform (Luma + Apple Event + Stripe Aesthetic).
- **Core Principles**:
  - Clean, spacious layout with deliberate whitespace.
  - Subtle multi-layered shadows instead of flat harsh borders.
  - Rounded, organic corners (`16px` to `24px`).
  - Tactile micro-interactions: Smooth hover lifts (`translateY(-4px)`), soft glows, glassmorphism (`backdrop-filter: blur(16px)`).
  - High-contrast, sharp typography with negative letter-spacing for headers.

## 2. Color Palette & Design Tokens
- **Background**:
  - Main Canvas: `#f8fafc` (Ultra clean Slate 50)
  - Card/Surface: `#ffffff`
  - Subtle Surface Alt: `#f1f5f9`
  - Dark Accent Surface: `#090d16` (Obsidian hero/footer contrast)
- **Primary Brand Glow**:
  - Primary Indigo/Violet: `#6366f1` to `#8b5cf6`
  - Vibrant Emerald (Tickets & Success): `#10b981` (Hover: `#059669`)
  - Warning/Hot Deal: `#f59e0b`
  - Critical/Urgent: `#ef4444`
- **Text & Hierarchy**:
  - Headings: `#0f172a` (Deep Slate, bold, `tracking-tight`)
  - Body: `#334155` (Slate 700)
  - Muted: `#64748b` (Slate 500)
  - Borders: `rgba(226, 232, 240, 0.8)` or `#e2e8f0`

## 3. Component Standards
- **Header**: Floating glassmorphic navigation bar, subtle border, smooth hover transitions.
- **Event Card**: 16:9 aspect ratio image, subtle gradient overlay, status chips with glowing dots, clear pricing hierarchy, smooth zoom on hover.
- **Hero Section**: High-impact title, dynamic search pill with instant tags, modern gradient background accents.
